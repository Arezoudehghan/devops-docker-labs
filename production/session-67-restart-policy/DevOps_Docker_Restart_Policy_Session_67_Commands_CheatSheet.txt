------------------------------------------------------------
# docker run -d --name web-app -p 8088:8000 my-app:v1

Explanation:
Runs the `my-app:v1` image as a detached container named `web-app` and publishes host port 8088 to container port 8000.

Options:
- `-d` = `--detach` (detach): Runs the container in the background.
- `--name web-app` = container name: Assigns the name `web-app` to the container.
- `-p 8088:8000` = `--publish` (publish): Maps host port `8088` to container port `8000`.
------------------------------------------------------------
# docker start web-app

Explanation:
Starts the existing stopped container named `web-app`.
------------------------------------------------------------
# docker run --restart=<POLICY> IMAGE

Explanation:
Shows the general Docker syntax for starting a container with a selected restart policy. Replace `<POLICY>` with a valid policy and `IMAGE` with the image to run.

Options:
- `--restart=<POLICY>` = restart policy: Defines how Docker should restart the container after it exits.
------------------------------------------------------------
# docker run -d --name web-app --restart=unless-stopped nginx

Explanation:
Runs Nginx in the background as `web-app` and automatically restarts it unless it was intentionally stopped.

- `--name web-app` = container name: Assigns the name `web-app` to the container.
- `--restart=unless-stopped` = restart policy: Restarts the container automatically unless it was manually stopped.
------------------------------------------------------------

# docker run -d --name app --restart=on-failure:3 my-app:v1

Explanation:
Runs `my-app:v1` as `app` and restarts it after failures, with a maximum of three restart retries.

Options:
- `-d` = `--detach` (detach): Runs the container in the background.
- `--name app` = container name: Assigns the name `app` to the container.
- `--restart=on-failure:3` = restart policy with retry limit: Restarts after non-zero exits and limits restart retries to `3`.

- `--name web-app` = container name: Assigns the name `web-app` to the container.
- `--restart=always` = restart policy: Restarts the container whenever it stops, subject to Docker's manual-stop behavior.
- `-p 8088:8000` = `--publish` (publish): Maps host port `8088` to container port `8000`.
- `\` = shell line continuation: Continues the same command on the next line.

# docker run -d \
  --name rp-test \
  --restart=on-failure:3 \
  alpine \
  sh -c 'sleep 12; exit 1'

Explanation:
Runs an Alpine test container that sleeps for 12 seconds and then exits with code `1` so the `on-failure:3` restart policy can be tested.

Options:
- `-d` = `--detach` (detach): Runs the container in the background.
- `--name rp-test` = container name: Assigns the name `rp-test` to the container.
- `--restart=on-failure:3` = restart policy with retry limit: Restarts after failed exits and limits restart retries to `3`.
- `-c` = command string: Tells `sh` to execute the following quoted command string.
- `;` = shell command separator: Runs `exit 1` after `sleep 12` finishes.
- `\` = shell line continuation: Continues the same command on the next line.
