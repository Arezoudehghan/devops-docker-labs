# HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
  CMD curl -f http://localhost:8000/health || exit 1

Explanation:
Defines a Dockerfile health check that requests the local `/health` endpoint and reports failure when the HTTP request fails.

Options:
- --interval=30s = health-check interval: Run the check every 30 seconds.
- --timeout=5s = health-check timeout: Allow each check up to 5 seconds.
- --retries=3 = consecutive failure threshold: Mark the container unhealthy after three failed checks.
- -f = --fail (fail): Make `curl` fail on HTTP response codes 400 or greater without normal response output.
- || = OR shell operator: Run `exit 1` only if the `curl` command fails.
- `exit 1` = nonzero shell exit status: Report the health-check command as failed.
- `\` = line continuation in the Dockerfile instruction: Continue the same `HEALTHCHECK` instruction on the next line.

# services:

  web:
    image: myapp:1.4
    depends_on:
      db:
        condition: service_healthy

  db:
    image: postgres:17
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 10s
      timeout: 5s
      retries: 5

Explanation:
This Docker Compose fragment makes `web` wait for the `db` service health check to become healthy before Compose starts `web`.

Options:
- `depends_on` = service dependency setting: Define that `web` depends on `db`.
- `condition: service_healthy` = dependency condition: Wait for the dependency health check to report healthy.
- `healthcheck` = service health-check configuration: Define how Compose checks the `db` service.
- `test` = health-check command: Run `pg_isready -U postgres` through a shell.
- -U = --username (username) in `pg_isready`: Check readiness using the database user `postgres`.
- `interval: 10s` = health-check interval: Run the check every 10 seconds.
- `timeout: 5s` = health-check timeout: Allow each check up to 5 seconds.
- `retries: 5` = consecutive failure threshold: Require five failed checks before the service is considered unhealthy.
------------------------------------------------------------
