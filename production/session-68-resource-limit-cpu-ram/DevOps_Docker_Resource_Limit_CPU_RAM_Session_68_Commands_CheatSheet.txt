# docker run -d \
  --name web \
  --memory="512m" \
  nginx:alpine

Explanation:
Runs an nginx:alpine container named web in the background with a 512 MB hard memory limit.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name web = --name: Assigns the container name web.
- --memory="512m" = --memory: Sets the hard memory limit to 512 MB; m means megabytes.

# docker run -d \
  --name production-web \
  --restart=unless-stopped \
  --cpus="1.0" \
  --memory="512m" \
  --memory-reservation="384m" \
  --memory-swap="512m" \
  -p 8080:80 \
  nginx:alpine

Explanation:
Runs a production-style nginx container with restart behavior, CPU and memory limits, no additional swap, and host port 8080 mapped to container port 80.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name production-web = --name: Assigns the container name production-web.
- --restart=unless-stopped = --restart: Restarts the container automatically unless it was explicitly stopped.
- --cpus="1.0" = --cpus: Limits CPU usage to the equivalent of 1.0 CPU.
- --memory="512m" = --memory: Sets the hard memory limit to 512 MB.
- --memory-reservation="384m" = --memory-reservation: Sets the soft memory reservation to 384 MB.
- --memory-swap="512m" = --memory-swap: Sets total RAM plus swap to 512 MB, so no additional swap is available.
- -p = --publish (publish): Publishes container port 80 on host port 8080; 8080:80 means host-port:container-port.

# docker run \
  --name ram-test \
  --memory="100m" \
  --memory-swap="100m" \
  python:3.12-slim \
  python -c 'a=bytearray(200*1024*1024); import time; time.sleep(60)'

Explanation:
Runs a Python container with a 100 MB memory limit while Python attempts to allocate about 200 MB, which is intended to trigger an out-of-memory condition.

Options:
- --name ram-test = --name: Assigns the container name ram-test.
- --memory="100m" = --memory: Sets the hard memory limit to 100 MB.
- --memory-swap="100m" = --memory-swap: Sets total RAM plus swap to 100 MB, so no additional swap is available.
- -c = command string for Python: Tells Python to execute the following quoted Python code.
- 200*1024*1024 = allocation size: Requests about 200 MiB with bytearray.
- time.sleep(60) = sleep argument: Keeps the process alive for 60 seconds if the allocation succeeds.
------------------------------------------------------------
