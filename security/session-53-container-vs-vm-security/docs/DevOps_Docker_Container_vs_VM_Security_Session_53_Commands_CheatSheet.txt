------------------------------------------------------------
# uname -r

Explanation:
Shows the kernel release of the current Linux system.

Options:
- -r = --kernel-release (kernel release): Prints the kernel release version.
------------------------------------------------------------
# docker run --rm python:3.12-slim uname -r

Explanation:
Starts a temporary container from the python:3.12-slim image and prints the kernel release seen inside the container. The container is removed automatically after the command finishes.

Options:
- --rm = automatically remove the container: Deletes the container when its process exits.
- python:3.12-slim = image reference: Uses the python image with the 3.12-slim tag.
- -r = --kernel-release (kernel release): Tells uname to print the kernel release.
------------------------------------------------------------

# docker run --rm \
  --mount type=bind,src=/,dst=/host,readonly \
  python:3.12-slim \
  sh -c 'ls -ld /host /host/etc /host/var'

Explanation:
Starts a temporary container with the host root filesystem bind-mounted read-only at /host, then lists selected mounted paths.

Options:
- --rm = automatically remove the container: Deletes the container when its process exits.
- --mount type=bind,src=/,dst=/host,readonly = mount specification: Creates a read-only bind mount from host / to container /host.
- type=bind = mount type value: Selects a bind mount.
- src=/ = source value: Uses the host root directory as the mount source.
- dst=/host = destination value: Mounts the source at /host inside the container.
- readonly = read-only mount setting: Prevents writes through this mount.
- -c = command string: Tells sh to execute the following quoted string as a command.
- -l = long listing format: Tells ls to use the long listing format.
- -d = --directory (directory): Tells ls to list the directory entries themselves instead of their contents.
- \ = shell line continuation: Continues the same command on the next line.

# docker run -d \
  --name sec53-limit \
  --memory=128m \
  --cpus=0.5 \
  python:3.12-slim \
  sleep infinity

Explanation:
Starts sec53-limit in the background with memory and CPU limits and keeps it running with sleep infinity.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name sec53-limit = container name: Assigns the name sec53-limit to the container.
- --memory=128m = memory limit: Limits container memory to 128 megabytes.
- --cpus=0.5 = CPU limit: Limits the container to the equivalent of half of one CPU.
- python:3.12-slim = image reference: Uses the python image with the 3.12-slim tag.
- infinity = sleep argument: Keeps the sleep process running indefinitely.
- \ = shell line continuation: Continues the same command on the next line.
