# docker run -d \
  --name env-demo \
  -e APP_MODE=production \
  -e DB_PASSWORD='SuperSecret_56!' \
  alpine:3.20 \
  sleep 3600

Explanation:
Starts an Alpine container named env-demo in the background and sets two environment variables. The container runs sleep for 3600 seconds.

Options:
- `-d` = `--detach` (detached mode): Runs the container in the background.
- `--name env-demo` = name option: Assigns the container name `env-demo`.
- `-e` = `--env` (environment): Sets an environment variable inside the container.
