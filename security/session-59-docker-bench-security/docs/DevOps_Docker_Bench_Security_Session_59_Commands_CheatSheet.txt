# docker run -d \
  --name bench-demo \
  --memory=128m \
  --cpus=0.50 \
  --pids-limit=100 \
  --read-only \
  --tmpfs /var/cache/nginx:rw,noexec,nosuid,size=16m \
  --tmpfs /var/run:rw,noexec,nosuid,size=4m \
  --security-opt no-new-privileges:true \
  --restart=on-failure:5 \
  -p 127.0.0.1:18059:80 \
  nginx:alpine

Explanation:
Creates and starts a hardened nginx container with memory, CPU, PID, filesystem, privilege, restart, and port-binding controls.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = container name: Assigns the name bench-demo.
- --memory=128m = memory limit: Limits container memory to 128 MiB.
- --cpus=0.50 = CPU limit: Limits the container to the equivalent of 0.50 CPU.
- --pids-limit=100 = PID limit: Limits the number of processes available to the container to 100.
- --read-only = read-only root filesystem: Mounts the container root filesystem as read-only.
- --tmpfs /var/cache/nginx:rw,noexec,nosuid,size=16m = tmpfs mount: Creates a writable 16 MiB temporary filesystem at /var/cache/nginx with noexec and nosuid restrictions.
- --tmpfs /var/run:rw,noexec,nosuid,size=4m = tmpfs mount: Creates a writable 4 MiB temporary filesystem at /var/run with noexec and nosuid restrictions.
- --security-opt no-new-privileges:true = security option: Prevents container processes from gaining additional privileges.
- --restart=on-failure:5 = restart policy: Restarts the container after failure, up to five retry attempts.
- -p = --publish (publish): Publishes a container port on the host.
- 127.0.0.1:18059:80 = publish value: Binds host loopback port 18059 to container port 80.
- \ = shell line continuation: Continues the same command on the next line.
