# cat > Dockerfile <<'EOF'
FROM python:3.12-slim

RUN mkdir -p /app \
    && chown 10001:10001 /app

WORKDIR /app

COPY --chown=10001:10001 index.html /app/index.html

USER 10001:10001

EXPOSE 8000

CMD ["python", "-m", "http.server", "8000", "--bind", "0.0.0.0"]
EOF

Explanation:
Creates the complete Dockerfile for the non-root web container. It prepares /app, assigns UID and GID 10001, copies the page with matching ownership, and starts Python's HTTP server on port 8000.

Options:
- > = shell output redirection: Replaces Dockerfile with the standard output produced by cat.
- <<'EOF' = quoted here-document: Sends the block to cat until EOF and prevents shell expansion inside the block.
- -p = --parents: Used by mkdir to create /app without failing if it already exists.
- \\ = shell line continuation: Continues the RUN instruction on the next physical line.
- && = shell AND operator: Runs chown only if mkdir succeeds.
- --chown=10001:10001 = Dockerfile COPY ownership option: Sets the copied file owner UID and GID to 10001.
- "-m" = Python module option: Runs the http.server module.
- "--bind" = Python http.server bind option: Binds the server to the specified address, 0.0.0.0.

# docker run --rm \

- type=bind = mount type: Uses a bind mount from a host path.
- src="$PWD/data" = mount source: Uses the data directory under the current host working directory.
- dst=/data = mount destination: Mounts the source directory at /data inside the container.
- $PWD = shell variable expansion: Expands to the current working directory before Docker receives the mount value.
- -c = command string: Tells sh to execute the following quoted command string.
- && = shell AND operator: Runs touch only if id succeeds.
- \\ = shell line continuation: Continues the same command on the next line.
