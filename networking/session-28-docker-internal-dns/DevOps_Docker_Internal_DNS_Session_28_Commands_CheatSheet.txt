------------------------------------------------------------
# docker network create app-net

Explanation:
Creates a user-defined Docker network named app-net.
------------------------------------------------------------
# docker network ls

Explanation:
Lists all Docker networks available on the host.
------------------------------------------------------------
# docker run -d \
  --name web1 \
  --network app-net \
  nginx

Explanation:
Starts an Nginx container named web1 in the background and connects it to the app-net network.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name web1 = container name: Sets the container name to web1.
- --network app-net = network: Connects the container to the app-net network.
- \ = shell line continuation: Continues the same command on the next line.
------------------------------------------------------------
# docker run -it \
  --name client1 \
  --network app-net \
  busybox sh

Explanation:
Starts an interactive BusyBox container named client1 on app-net and opens the sh shell.

Options:
- -i = --interactive (interactive): Keeps standard input open for interactive use.
- -t = --tty (TTY): Allocates a pseudo-TTY.
- --name client1 = container name: Sets the container name to client1.
- --network app-net = network: Connects the container to the app-net network.
- \ = shell line continuation: Continues the same command on the next line.

# docker run -d \
  --name mysql-prod-01 \
  --network app-net \
  --network-alias database \
  mysql:8

Explanation:
Starts a MySQL 8 container named mysql-prod-01 on app-net and gives it the network alias database.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name mysql-prod-01 = container name: Sets the container name to mysql-prod-01.
- --network app-net = network: Connects the container to the app-net network.
- --network-alias database = network alias: Adds database as a network-scoped alias for the container.
- \ = shell line continuation: Continues the same command on the next line.
