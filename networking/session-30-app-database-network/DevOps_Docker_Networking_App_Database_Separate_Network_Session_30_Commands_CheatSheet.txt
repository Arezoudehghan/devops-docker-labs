# docker run -d \
  --name db \
  --network app-db-net \
  -e MYSQL_ROOT_PASSWORD=RootPass123 \
  -e MYSQL_DATABASE=appdb \
  -e MYSQL_USER=appuser \
  -e MYSQL_PASSWORD=AppPass123 \
  -v mysql_data:/var/lib/mysql \
  mysql:8.4

Explanation:
Starts a MySQL 8.4 container named db on app-db-net with an application database, user credentials, and persistent storage.

Options:
- -d = --detach (detach): Run the container in the background.
- --name db = container name: Assign the name db to the container.
- --network app-db-net = network: Connect the container to app-db-net.
- -e = --env (environment): Set an environment variable inside the container.
- MYSQL_ROOT_PASSWORD=RootPass123 = environment variable value: Set the MySQL root password.
- MYSQL_DATABASE=appdb = environment variable value: Create the appdb database during initialization.
- MYSQL_USER=appuser = environment variable value: Create the appuser MySQL user during initialization.
- MYSQL_PASSWORD=AppPass123 = environment variable value: Set the password for appuser.
- -v = --volume (volume): Mount a volume into the container.
- mysql_data:/var/lib/mysql = volume mapping: Mount mysql_data at /var/lib/mysql inside the container.

# docker run -d \
  --name app \
  --network app-db-net \
  -p 8080:80 \
  -e WORDPRESS_DB_HOST=db:3306 \
  -e WORDPRESS_DB_NAME=appdb \
  -e WORDPRESS_DB_USER=appuser \
  -e WORDPRESS_DB_PASSWORD=AppPass123 \
  wordpress:latest

Explanation:
Starts a WordPress container named app on app-db-net and publishes the application on host port 8080.

Options:
- -d = --detach (detach): Run the container in the background.
- --name app = container name: Assign the name app to the container.
- --network app-db-net = network: Connect the container to app-db-net.
- -p = --publish (publish): Publish a container port on the Docker host.
- 8080:80 = port mapping: Map host port 8080 to container port 80.
- -e = --env (environment): Set an environment variable inside the container.
- WORDPRESS_DB_HOST=db:3306 = environment variable value: Tell WordPress to connect to the database host db on port 3306.
- WORDPRESS_DB_NAME=appdb = environment variable value: Tell WordPress to use the appdb database.
- WORDPRESS_DB_USER=appuser = environment variable value: Set the database username used by WordPress.
- WORDPRESS_DB_PASSWORD=AppPass123 = environment variable value: Set the database password used by WordPress.

Explanation:
Runs a PHP command inside the running app container to resolve the Docker DNS name db and print its IP address.

Options:
- -r = run PHP code: Execute the provided PHP code directly without a script file.

# docker run --rm \
  --network app-db-net \
  mysql:8.4 \
  mysql \
  -h db \
  -uappuser \
  -pAppPass123 \
  -e "SELECT 1;"

Explanation:
Starts a temporary MySQL client container on app-db-net and tests a connection to db by executing SELECT 1.

Options:
- --rm = remove automatically: Remove the temporary container automatically after it exits.
- --network app-db-net = network: Connect the temporary container to app-db-net.
- -h = --host (host): Connect the MySQL client to the host named db.
- -uappuser = --user=appuser (user): Authenticate as the MySQL user appuser.
- -pAppPass123 = --password=AppPass123 (password): Use AppPass123 as the MySQL password.
- -e = --execute (execute): Execute the SQL statement and exit.
------------------------------------------------------------

- -c 2 = count: Send exactly two ICMP echo requests.

# EXPOSE 3306

Explanation:
Declares in a Dockerfile that the image is intended to listen on port 3306. It does not publish the port on the Docker host.

Options:
- 3306 = port argument: Declare TCP port 3306 as the container's intended listening port.
