------------------------------------------------------------
# docker run -d \
  --name web \
  -p 8080:80 \
  nginx:alpine

Explanation:
Runs an Nginx container in detached mode and publishes host port 8080 to container port 80.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name web = --name: Assigns the container name `web`.
- -p 8080:80 = --publish 8080:80 (publish): Maps host port 8080 to container port 80.
------------------------------------------------------------
# docker run -d \
  --name host-nginx \
  --network host \
  nginx:alpine

Explanation:
Runs an Nginx container with the host network stack instead of a separate Docker network namespace.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name host-nginx = --name: Assigns the container name `host-nginx`.
- --network host = --network: Connects the container to the `host` network mode.
------------------------------------------------------------
# docker run -d \
  --name web \
  --network host \
  -p 8080:80 \
  nginx:alpine

Explanation:
Runs Nginx in host network mode. The `-p 8080:80` publishing option is accepted by Docker but is ignored in host network mode because the container already uses the host network stack.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name web = --name: Assigns the container name `web`.
- --network host = --network: Uses the host network stack.
- -p 8080:80 = --publish 8080:80 (publish): Requests host-to-container port publishing, but Docker ignores it when host networking is used.

Reads the container configuration and prints only its configured network mode.

# sudo ss -lntp

Explanation:
Displays listening TCP sockets with numeric addresses and associated process information.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket.
------------------------------------------------------------
# sudo ss -lntp | grep ':80'

Explanation:
Shows listening TCP sockets and filters the result to lines containing `:80`.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket.
- | = pipe operator: Sends the output of `ss` to `grep`.

# docker run -d \
  --name host-nginx-2 \
  --network host \
  nginx:alpine

Explanation:
Runs a second Nginx container in host network mode. It may fail if another process already owns the same host port that Nginx tries to use.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name host-nginx-2 = --name: Assigns the container name `host-nginx-2`.
- --network host = --network: Uses the host network stack.
