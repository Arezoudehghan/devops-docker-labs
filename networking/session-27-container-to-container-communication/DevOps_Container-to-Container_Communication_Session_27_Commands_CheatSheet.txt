------------------------------------------------------------
# docker network create app-network

Explanation:
Creates a user-defined Docker bridge network named app-network.
------------------------------------------------------------

------------------------------------------------------------
# docker network ls

Explanation:
Lists the Docker networks available on the host.
------------------------------------------------------------

------------------------------------------------------------
# docker run -d \
  --name web \
  --network app-network \
  nginx:alpine

Explanation:
Starts an nginx:alpine container named web in the background and attaches it to app-network.

Options:
- -d = --detach (detach): Run the container in the background.
- --name web = container name: Assign the name web to the container.
- --network app-network = network: Connect the container to app-network.

# docker run -d \
  --name web \
  --network app-network \
  -p 8080:80 \
  nginx

Explanation:
Starts an nginx container named web and publishes container port 80 on host port 8080.

Options:
- -d = --detach (detach): Run the container in the background.
- --name web = container name: Assign the name web to the container.
- --network app-network = network: Connect the container to app-network.
- -p 8080:80 = --publish 8080:80 (publish): Map host port 8080 to container port 80.
------------------------------------------------------------

# docker run -d \
  --name db \
  --network app-network \
  -p 5432:5432 \
  -e POSTGRES_PASSWORD=example \
  postgres

Explanation:
Technical correction: the original lesson command did not set the required PostgreSQL password, so -e POSTGRES_PASSWORD=example was added. This starts PostgreSQL as db, attaches it to app-network, and publishes port 5432.

Options:
- -d = --detach (detach): Run the container in the background.
- --name db = container name: Assign the name db to the container.
- --network app-network = network: Connect the container to app-network.
- -p 5432:5432 = --publish 5432:5432 (publish): Map host port 5432 to container port 5432.
- -e POSTGRES_PASSWORD=example = --env POSTGRES_PASSWORD=example (environment): Set the PostgreSQL password environment variable required by the image.
