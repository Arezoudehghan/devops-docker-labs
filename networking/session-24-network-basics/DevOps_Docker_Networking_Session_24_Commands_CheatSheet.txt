------------------------------------------------------------
# docker network ls

Explanation:
Lists all Docker networks available on the current Docker host.
------------------------------------------------------------
# docker run -d --name web nginx

Explanation:
Creates and starts an nginx container named web in detached mode.

Options:
- -d = --detach (detach): Run the container in the background.
- --name web = container name: Assign the name web to the container.
------------------------------------------------------------
# docker inspect web

Explanation:
Shows detailed Docker metadata and configuration for the container named web.
------------------------------------------------------------
# docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' web

Explanation:
Shows the IP address assigned to the container named web by formatting the inspect output.

Options:
- -f = --format (format): Format the output with the supplied Go template.
- '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' = format value: Iterate through the container networks and print each IPAddress value.
------------------------------------------------------------
# docker run -it --rm alpine sh

Explanation:
Starts a temporary interactive Alpine container and opens the sh shell.

Options:
- -i = --interactive (interactive): Keep standard input open for interactive use.
- -t = --tty (TTY): Allocate a pseudo-terminal.
- --rm = automatically remove container: Delete the container automatically when it exits.
------------------------------------------------------------
# ip addr

Explanation:
Displays network interfaces and their assigned IP addresses.
------------------------------------------------------------
# docker run -d --name web1 -p 8080:80 nginx

Explanation:
Starts an nginx container named web1 in the background and publishes host port 8080 to container port 80.

Options:
- -d = --detach (detach): Run the container in the background.
- --name web1 = container name: Assign the name web1 to the container.
- -p = --publish (publish): Publish a container port on the Docker host.
- 8080:80 = publish value: Map host port 8080 to container port 80.
------------------------------------------------------------

# docker run --rm alpine ping -c 4 8.8.8.8

Explanation:
Runs ping inside a temporary Alpine container and sends four ICMP echo requests to 8.8.8.8.

Options:
- --rm = automatically remove container: Delete the container automatically when the ping command finishes.
- -c 4 = count 4 packets: Stop after sending four echo requests.
------------------------------------------------------------
# docker run --rm alpine ping -c 4 google.com

Explanation:
Runs ping inside a temporary Alpine container and sends four ICMP echo requests to google.com, which also tests DNS name resolution.

Options:
- --rm = automatically remove container: Delete the container automatically when the ping command finishes.
- -c 4 = count 4 packets: Stop after sending four echo requests.
------------------------------------------------------------
# docker run --rm alpine cat /etc/resolv.conf

Explanation:
Starts a temporary Alpine container and prints its DNS resolver configuration file.

Options:
- --rm = automatically remove container: Delete the container automatically when the cat command finishes.
- /etc/resolv.conf = path argument: Read the container file that contains DNS resolver settings.

# docker run -d -p 127.0.0.1:8080:80 nginx

Explanation:
Starts nginx in the background and publishes container port 80 only on the host loopback address at port 8080.

Options:
- -d = --detach (detach): Run the container in the background.
- -p = --publish (publish): Publish a container port on the Docker host.
- 127.0.0.1:8080:80 = publish value: Bind host address 127.0.0.1 and host port 8080 to container port 80.

# ss -lntp

Explanation:
Shows listening TCP sockets using numeric addresses and ports, together with process information.

Options:
- -l = --listening (listening): Show only listening sockets.
- -n = --numeric (numeric): Do not resolve service names; show numeric addresses and port numbers.
- -t = --tcp (TCP): Show TCP sockets.
- -p = --processes (processes): Show the process using each socket when permission allows it.
