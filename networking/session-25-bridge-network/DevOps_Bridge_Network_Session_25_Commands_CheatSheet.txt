------------------------------------------------------------
# docker network ls

Explanation:
Lists all Docker networks available on the Docker host.
------------------------------------------------------------
# ip addr show docker0

Explanation:
Shows the IP address and interface details of the Linux docker0 bridge interface.
------------------------------------------------------------
# docker run -d --name web nginx

Explanation:
Starts an Nginx container in detached mode with the name web.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = container name: Assigns the name web to the container.
------------------------------------------------------------
# docker inspect web

Explanation:
Displays detailed Docker metadata and configuration for the container named web.
------------------------------------------------------------
# docker network inspect bridge

Explanation:
Displays detailed configuration and connected-container information for the default Docker bridge network.
------------------------------------------------------------
# docker run -dit --name container1 alpine sh

Explanation:
Starts an Alpine container named container1 in the background with an interactive TTY and runs sh.

Options:
- -d = --detach (detach): Runs the container in the background.
- -i = --interactive (interactive): Keeps standard input open.
- -t = --tty (TTY): Allocates a pseudo-TTY.
- --name = container name: Assigns the name container1 to the container.

# docker exec container1 ping -c 3 172.17.0.3

Explanation:

Options:
- -c = count: Tells ping to stop after sending 3 echo requests.
------------------------------------------------------------

Explanation:

- -f = --force (force): Forces removal of running containers by sending a kill signal first.

# docker run -d \
  --name db \
  --network backend-network \
  -e POSTGRES_PASSWORD='change-me-before-use' \
  postgres

Explanation:
Technical correction: The lesson command did not provide the required PostgreSQL initialization password, so this corrected command adds POSTGRES_PASSWORD. It starts a PostgreSQL container named db on backend-network.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = container name: Assigns the name db.
- --network = network: Connects the container to backend-network.
- -e = --env (environment): Sets the container environment variable POSTGRES_PASSWORD.
- POSTGRES_PASSWORD='change-me-before-use' = environment variable value: Provides an initialization password; replace this example value before real use.
- \ = shell line continuation: Continues the same shell command on the next line.

# docker run -d \
  --name web \
  --network app-network \
  -p 8080:8080 \
  myapp

Explanation:
Starts the myapp container named web, connects it to app-network, and publishes container port 8080 on host port 8080.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = container name: Assigns the name web.
- --network = network: Connects the container to app-network.
- -p = --publish (publish): Maps host port 8080 to container port 8080.
- \ = shell line continuation: Continues the same shell command on the next line.

# docker network create \
  --driver bridge \
  --subnet 172.30.0.0/24 \
  --gateway 172.30.0.1 \
  production-net

Explanation:
Creates a user-defined bridge network named production-net with a fixed subnet and gateway.

Options:
- --driver = network driver: Selects bridge as the network driver.
- --subnet = subnet in CIDR notation: Sets the network subnet to 172.30.0.0/24.
- --gateway = gateway address: Sets the network gateway to 172.30.0.1.
- \ = shell line continuation: Continues the same shell command on the next line.
