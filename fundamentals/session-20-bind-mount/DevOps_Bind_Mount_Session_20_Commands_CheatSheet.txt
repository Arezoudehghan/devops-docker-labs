------------------------------------------------------------
# mkdir -p /opt/demo-data

Explanation:
Creates the /opt/demo-data directory on the host. Parent directories are also created if they do not already exist.

Options:
- -p = --parents (parents): Create parent directories as needed and do not report an error if the directory already exists.
------------------------------------------------------------

------------------------------------------------------------
# docker run -d \
  --name bind-test \
  -v /opt/demo-data:/data \
  nginx

Explanation:
Starts an Nginx container named bind-test in the background and bind-mounts /opt/demo-data from the host to /data inside the container.

Options:
- -d = --detach (detach): Run the container in the background.
- --name = container name: Assign the name bind-test to the container.
- -v = --volume (volume): Mount /opt/demo-data on the host at /data inside the container.
------------------------------------------------------------

------------------------------------------------------------

Options:
- -i = --interactive (interactive): Keep standard input open.
- -t = --tty (TTY): Allocate a pseudo-TTY for the interactive shell.

# docker run -d \
  --name bind-test \
  --mount type=bind,source=/opt/demo-data,target=/data \
  nginx

Explanation:
Starts an Nginx container named bind-test in the background and creates a bind mount using the explicit --mount syntax.

Options:
- -d = --detach (detach): Run the container in the background.
- --name = container name: Assign the name bind-test to the container.
- --mount = mount specification: Attach a filesystem mount to the container.
- type=bind = bind mount type: Use a host path as the mount source.
- source=/opt/demo-data = mount source: Use /opt/demo-data on the host.
- target=/data = mount target: Make the mount available at /data inside the container.
------------------------------------------------------------
