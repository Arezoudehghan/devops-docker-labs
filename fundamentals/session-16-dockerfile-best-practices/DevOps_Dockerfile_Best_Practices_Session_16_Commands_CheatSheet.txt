# RUN apt-get update \
    && apt-get install -y --no-install-recommends curl \
    && rm -rf /var/lib/apt/lists/*

Explanation:
Updates APT package metadata, installs curl without recommended packages, and removes cached APT package lists in the same image layer.

Options:
- -y = --assume-yes (assume yes): Automatically answers yes to installation prompts.
- --no-install-recommends = do not install recommended packages: Installs only required dependencies instead of recommended extras.
- -r in rm -rf = --recursive (recursive): Removes directories and their contents recursively.
- -f in rm -rf = --force (force): Ignores nonexistent files and does not prompt.
- && = AND operator: Runs the next command only if the previous command succeeds.
- \ = line continuation: Continues the same shell command on the next line.
- /var/lib/apt/lists/* = path pattern: Matches all files and directories inside the APT package-list directory.

# docker run -d \
  --name best-app \
  -p 8080:5000 \
  best-app:v1

Explanation:
Starts a container from best-app:v1 in detached mode, names it best-app, and publishes container port 5000 on host port 8080.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name best-app = container name: Assigns the name best-app to the container.
- -p = --publish (publish): Publishes a container port on the host.
- 8080:5000 = port mapping: Maps host port 8080 to container port 5000.
- \ = line continuation: Continues the same shell command on the next line.
