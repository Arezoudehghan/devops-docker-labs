------------------------------------------------------------
# docker run nginx

Explanation:
Creates and starts a new container from the `nginx` image in the foreground.
------------------------------------------------------------

------------------------------------------------------------
# docker run -d nginx

Explanation:
Creates and starts a new container from the `nginx` image in detached mode so the terminal returns immediately.

Options:
- -d = --detach (detach): Run the container in the background and print its container ID.
------------------------------------------------------------

------------------------------------------------------------
# docker ps

Explanation:
Lists containers that are currently running.
------------------------------------------------------------

------------------------------------------------------------
# docker run -d --name web1 nginx

Explanation:
Creates and starts a detached Nginx container and assigns it the name `web1`.

Options:
- -d = --detach (detach): Run the container in the background and print its container ID.
- --name = name: Assign the custom container name `web1`.
------------------------------------------------------------

------------------------------------------------------------
# docker logs web1

Explanation:
Displays the logs produced by the container named `web1`.
------------------------------------------------------------

------------------------------------------------------------
# docker logs -f web1

Explanation:
Displays the logs from `web1` and keeps following new log output as it is produced.

Options:
- -f = --follow (follow): Continue streaming new log output.
------------------------------------------------------------

------------------------------------------------------------
# docker run --name web2 nginx

Explanation:
Creates and starts an Nginx container in the foreground and assigns it the name `web2`.

Options:
- --name = name: Assign the custom container name `web2`.
------------------------------------------------------------

------------------------------------------------------------
# docker ps -a

Explanation:
Lists all containers, including both running and stopped containers.

Options:
- -a = --all (all): Show all containers instead of only running containers.
------------------------------------------------------------

------------------------------------------------------------
# docker run --name fg-test nginx

Explanation:
Creates and starts an Nginx container in the foreground and names it `fg-test`.

Options:

------------------------------------------------------------
# docker attach bg-test

Explanation:
Attaches the current terminal to the main process of the running container named `bg-test`.
------------------------------------------------------------

------------------------------------------------------------
# docker exec -it bg-test /bin/bash

Explanation:
Starts a new interactive Bash process inside the running container named `bg-test`.

Options:
- -i = --interactive (interactive): Keep standard input open even when not attached.
- -t = --tty (TTY): Allocate a pseudo-TTY for the command.
------------------------------------------------------------

------------------------------------------------------------
# docker exec -it bg-test /bin/sh

Explanation:
Starts a new interactive `sh` shell inside the running container named `bg-test`.

Options:
- -i = --interactive (interactive): Keep standard input open even when not attached.
- -t = --tty (TTY): Allocate a pseudo-TTY for the command.

# docker run alpine echo "Hello Docker"

Explanation:
Creates an Alpine container, runs `echo "Hello Docker"` as its main process, and stops when that process finishes.
------------------------------------------------------------

------------------------------------------------------------
# docker run -d alpine echo "Hello Docker"

Explanation:
Creates an Alpine container in detached mode, runs `echo "Hello Docker"`, and exits when the echo process finishes.

Options:
- -d = --detach (detach): Run the container in the background and print its container ID.
------------------------------------------------------------

------------------------------------------------------------
# docker run -it ubuntu bash

Explanation:
Creates an Ubuntu container and starts an interactive Bash shell in the foreground.

Options:
- -i = --interactive (interactive): Keep standard input open even when not attached.
- -t = --tty (TTY): Allocate a pseudo-TTY for the shell.
