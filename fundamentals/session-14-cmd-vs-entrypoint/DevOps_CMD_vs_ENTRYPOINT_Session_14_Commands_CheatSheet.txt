# docker run --rm -it --entrypoint /bin/sh myapp

Explanation:
Starts an interactive shell in a container from `myapp` while overriding the image's ENTRYPOINT, then removes the container after exit.

Options:
- --rm = automatically remove the container: Deletes the container when it exits.
- -i = --interactive (interactive): Keeps standard input open.
- -t = --tty (TTY): Allocates a pseudo-terminal.
- --entrypoint = override image ENTRYPOINT: Uses `/bin/sh` instead of the image's configured ENTRYPOINT.

# cat > Dockerfile.cmd <<'EOF'
FROM alpine:latest

CMD ["echo", "Hello from CMD"]
EOF

Explanation:
Creates `Dockerfile.cmd` and writes the shown Dockerfile content into it using a quoted here-document.

Options:
- > = shell output redirection: Writes the command output to `Dockerfile.cmd`, replacing existing file content.
- <<'EOF' = quoted here-document operator: Supplies the following lines as standard input until the closing `EOF`, without shell expansion.
------------------------------------------------------------
# docker build -f Dockerfile.cmd -t cmd-demo .

Explanation:
Builds a Docker image named `cmd-demo` using `Dockerfile.cmd` and the current directory as the build context.

Options:
- -f = --file (file): Selects `Dockerfile.cmd` as the Dockerfile.
- -t = --tag (tag): Names and tags the resulting image as `cmd-demo`.
- . = build context: Uses the current directory as the Docker build context.
------------------------------------------------------------
