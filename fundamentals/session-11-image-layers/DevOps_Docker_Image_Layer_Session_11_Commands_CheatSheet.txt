# docker run nginx

Explanation:
Creates and starts a container from the nginx image in the foreground.
------------------------------------------------------------
# docker run -d --name web1 nginx

Explanation:
Creates and starts a container named web1 from the nginx image in detached mode.

Options:
- -d = --detach (detach): Runs the container in the background and prints its container ID.
- --name web1 = --name: Assigns the container name web1.

Explanation:
Refreshes the APT package index during the Docker image build.
------------------------------------------------------------
# RUN apt-get install -y curl

Explanation:
Installs the curl package during the Docker image build and automatically accepts confirmation prompts.

Options:
- -y = --yes / --assume-yes (assume yes): Automatically answers yes to installation confirmation prompts.
------------------------------------------------------------
# RUN apt-get update && \
    apt-get install -y curl

Explanation:
Refreshes the APT package index and, only if that succeeds, installs curl in the same Dockerfile RUN instruction.

Options:
- && = AND operator: Runs the second command only if the first command exits successfully.
- \ = line continuation: Continues the same shell command on the next line.
- -y = --yes / --assume-yes (assume yes): Automatically answers yes to installation confirmation prompts.
