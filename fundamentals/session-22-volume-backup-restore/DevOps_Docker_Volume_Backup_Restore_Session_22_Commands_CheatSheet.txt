# docker volume inspect app-data

Explanation:
Shows detailed metadata and configuration for the app-data volume.

------------------------------------------------------------
# docker run --rm \
  -v app-data:/data \
  alpine \
  sh -c 'echo "Hello from Docker Volume" > /data/file1.txt'

Explanation:
Runs a temporary Alpine container, mounts app-data at /data, and writes text into /data/file1.txt.

Options:
- --rm = remove container automatically: Deletes the container after the command finishes.
- -v = --volume: Mounts app-data from Docker into /data inside the container.
- -c = command string: Tells sh to execute the following quoted shell command.
- > = output redirection: Writes the output of echo to /data/file1.txt, replacing the file if it already exists.
------------------------------------------------------------
# docker run --rm \
  -v app-data:/data \
  alpine \
  cat /data/file1.txt

Explanation:
Runs a temporary Alpine container and reads file1.txt from the app-data volume.

Options:
- --rm = remove container automatically: Deletes the container after the command finishes.
- -v = --volume: Mounts app-data from Docker into /data inside the container.

# docker run --rm \
  -v app-data:/data:ro \
  -v ~/docker-backups:/backup \
  alpine \
  tar czf /backup/app-data-backup.tar.gz -C /data .

Explanation:
Runs a temporary Alpine container and creates a gzip-compressed backup of the app-data volume in ~/docker-backups.

Options:
- --rm = remove container automatically: Deletes the container after the backup command finishes.
- -v = --volume: Mounts Docker volumes or host paths into the container.
- :ro = read-only mount mode: Mounts app-data so the backup container cannot modify it.
- c = --create: Creates a new tar archive.
- z = --gzip: Compresses the archive with gzip.
- f = --file: Uses /backup/app-data-backup.tar.gz as the archive file.
- -C = --directory: Changes to /data before archiving.
- . = current directory argument: Archives all content under /data.
------------------------------------------------------------

- z = --gzip: Reads the archive through gzip decompression.

# docker exec mysql-db \
  mysqldump -u root -p mydatabase > ~/docker-backups/mydatabase.sql

Explanation:
Runs mysqldump inside mysql-db and writes the SQL dump to ~/docker-backups/mydatabase.sql on the Docker host.

Options:
- -u = --user: Uses root as the MySQL user.
- -p = --password: Requests a MySQL password without placing the password value directly in the command.
- > = output redirection: Writes standard output from docker exec into ~/docker-backups/mydatabase.sql, replacing the file if it already exists.
------------------------------------------------------------
# docker exec -i mysql-db \
  mysql -u root -p mydatabase < ~/docker-backups/mydatabase.sql

Explanation:
Runs the MySQL client inside mysql-db and sends the SQL backup file to it for restore.

Options:
- -i = --interactive: Keeps standard input open for the docker exec process.
- -u = --user: Uses root as the MySQL user.
- -p = --password: Requests a MySQL password without placing the password value directly in the command.
- < = input redirection: Sends ~/docker-backups/mydatabase.sql to the standard input of the docker exec command.

# docker run --rm \
  -v app-data:/data:ro \
  -v ~/docker-backups:/backup \
  alpine \
  sh -c 'tar czf /backup/app-data-$(date +%F-%H%M).tar.gz -C /data .'

Explanation:
Runs a temporary Alpine container and creates a timestamped gzip-compressed backup of app-data.

Options:
- --rm = remove container automatically: Deletes the container after the backup command finishes.
- -v = --volume: Mounts the Docker volume and host backup directory into the container.
- :ro = read-only mount mode: Mounts app-data so the backup container cannot modify it.
- -c = command string: Tells sh to execute the following quoted shell command.
- c = --create: Creates a new tar archive.
- z = --gzip: Compresses the archive with gzip.
- f = --file: Uses the generated timestamped path as the archive file.
- -C = --directory: Changes to /data before archiving.
- . = current directory argument: Archives all content under /data.
- $(...) = command substitution: Runs date +%F-%H%M and inserts its output into the backup filename.
- +%F-%H%M = date format argument: Produces a date and time value using %F for YYYY-MM-DD, %H for hour, and %M for minute.
