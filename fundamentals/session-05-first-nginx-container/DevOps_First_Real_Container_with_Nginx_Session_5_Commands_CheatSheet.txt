# docker run -d --name my-nginx nginx

Explanation:
Creates and starts an Nginx container in the background and assigns it the name `my-nginx`.

Options:
- -d = --detach (detach): Runs the container in the background and prints the container ID.
- --name my-nginx = name: Assigns the container name `my-nginx`.

# docker run -d --name my-nginx -p 8080:80 nginx

Explanation:
Creates and starts an Nginx container named `my-nginx` in the background and maps host port `8080` to container port `80`.

Options:
- -d = --detach (detach): Runs the container in the background and prints the container ID.
- --name my-nginx = name: Assigns the container name `my-nginx`.
- -p 8080:80 = --publish 8080:80 (publish): Publishes host port `8080` to container port `80`.

# ps aux

Explanation:
Shows running processes with user-oriented details, including processes without a controlling terminal.

Options:
- a = documented BSD-style option: Shows processes for all users, not only the current user.
- u = documented BSD-style option: Uses a user-oriented output format.
- x = documented BSD-style option: Includes processes that do not have a controlling terminal.

# docker inspect -f '{{range .NetworkSettings.Networks}}{{.IPAddress}}{{end}}' my-nginx

# docker run -d --name nginx-2 -p 8081:80 nginx

Options:

- --name nginx-2 = name: Assigns the container name `nginx-2`.
- -p 8081:80 = --publish 8081:80 (publish): Publishes host port `8081` to container port `80`.

------------------------------------------------------------
# docker run -d --name nginx-3 -p 8080:80 nginx

Explanation:
Attempts to create and start a third Nginx container named `nginx-3` while publishing host port `8080`. The syntax is valid, but it fails at runtime if host port `8080` is already allocated.

Options:
- -d = --detach (detach): Runs the container in the background and prints the container ID.
- --name nginx-3 = name: Assigns the container name `nginx-3`.
- -p 8080:80 = --publish 8080:80 (publish): Publishes host port `8080` to container port `80`.
------------------------------------------------------------

# ss -lntp

Explanation:
Shows listening TCP sockets with numeric addresses and the related process information.

Options:
- -l = --listening (listening): Displays only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving service names.
- -t = --tcp (TCP): Displays TCP sockets.
- -p = --processes (processes): Shows the process using each socket.
