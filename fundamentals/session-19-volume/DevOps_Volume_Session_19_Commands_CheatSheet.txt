# docker run -d \
  --name mysql-db \
  -e MYSQL_ROOT_PASSWORD=123456 \
  mysql:8

Explanation:
Starts a MySQL 8 container in the background with the name mysql-db and sets the root password environment variable.

Options:
- -d = --detach (detach): Runs the container in the background and prints the container ID.
- --name = container name: Assigns the name mysql-db to the container.
- -e = --env (environment): Sets MYSQL_ROOT_PASSWORD=123456 inside the container.
- \ = shell line continuation: Continues the same command on the next line.

# docker run -d \
  --name test \
  --mount type=volume,source=mydata,target=/data \
  alpine \
  sleep infinity

Explanation:
Starts an Alpine container named test and mounts the mydata named volume at /data using --mount syntax.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = container name: Assigns the name test to the container.
- --mount = mount specification: Creates a mount with type=volume, source=mydata, and target=/data.
- type=volume = mount type value: Selects a Docker volume mount.
- source=mydata = mount source value: Uses the named volume mydata as the source.
- target=/data = mount target value: Mounts the volume at /data inside the container.
- \ = shell line continuation: Continues the same command on the next line.
