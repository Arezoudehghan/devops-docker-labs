# docker run -d \
  --name mysql-db \
  -e MYSQL_ROOT_PASSWORD='LabPass123!' \
  -e MYSQL_DATABASE=appdb \
  -v mysql_data:/var/lib/mysql \
  mysql:8.4

Explanation:
Runs a MySQL 8.4 container named mysql-db in detached mode and stores its database files in the mysql_data named volume.

Options:
- -d = --detach (detach): Run the container in the background and print its container ID.
- --name = container name: Assign the name mysql-db to the container.
- -e = --env (environment): Set an environment variable inside the container. It is used here for MYSQL_ROOT_PASSWORD and MYSQL_DATABASE.
- -v = --volume (volume): Mount mysql_data at /var/lib/mysql inside the container.
- \ = shell line continuation: Continue the same shell command on the next line.
------------------------------------------------------------

# docker exec mysql-db mysqladmin ping -uroot -p'LabPass123!'

Explanation:
Runs mysqladmin inside mysql-db and checks whether the MySQL server is responding.

Options:
- -u = --user (user): Connect as the MySQL user root.
- -p = --password[=password] (password): Use LabPass123! as the MySQL password.
------------------------------------------------------------
# docker exec -it mysql-db mysql -uroot -p

Explanation:
Starts an interactive MySQL client session inside mysql-db and prompts for the root password.

Options:
- -i = --interactive (interactive): Keep standard input open.
- -t = --tty (TTY): Allocate a pseudo-terminal.
- -u = --user (user): Connect as the MySQL user root.
- -p = --password[=password] (password): Prompt for the MySQL password because no password value is attached.

# docker exec mysql-db-new \
  mysqldump -uroot -p'LabPass123!' appdb > appdb.sql

Explanation:
Runs mysqldump inside mysql-db-new and writes a logical backup of appdb to appdb.sql on the Docker host.

Options:
- -u = --user (user): Connect as the MySQL user root.
- -p = --password[=password] (password): Use LabPass123! as the MySQL password.
- appdb = database argument: Dump the database named appdb.
- > = output redirection: Write standard output to appdb.sql and overwrite the file if it already exists.
- \ = shell line continuation: Continue the same shell command on the next line.
------------------------------------------------------------

Options:
- -e = --env (environment): Set MYSQL_ROOT_PASSWORD inside the container.
