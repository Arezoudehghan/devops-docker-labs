------------------------------------------------------------
# docker run -d --name web nginx

Explanation:
Creates and starts a new nginx container named web in detached mode.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name web = name: Assigns the container name web.

# docker run -d --name web01 -p 8080:80 nginx

Explanation:
Creates a detached nginx container named web01 and publishes container port 80 on host port 8080.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name web01 = name: Assigns the container name web01.
- -p 8080:80 = --publish 8080:80 (publish): Maps host port 8080 to container port 80.

------------------------------------------------------------
# ss -ltnp

Explanation:
Displays listening TCP sockets with numeric ports and associated processes when permitted.

Options:
- -l = --listening (listening): Shows listening sockets.
- -t = --tcp (TCP): Shows TCP sockets.
- -n = --numeric (numeric): Keeps addresses and ports numeric.
- -p = --processes (processes): Shows associated processes.
------------------------------------------------------------

------------------------------------------------------------
# ss -ltnp | grep 8080

Explanation:
Shows listening TCP sockets and filters lines containing 8080.

Options:
- -l = --listening (listening): Shows listening sockets.
- -t = --tcp (TCP): Shows TCP sockets.
- -n = --numeric (numeric): Keeps addresses and ports numeric.
- -p = --processes (processes): Shows associated processes.
- | = pipe operator: Sends ss output to grep.
