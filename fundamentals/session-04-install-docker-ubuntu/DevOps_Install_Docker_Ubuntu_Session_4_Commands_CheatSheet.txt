# sudo apt remove $(dpkg --get-selections docker.io docker-compose docker-compose-v2 docker-doc docker-buildx podman-docker containerd runc | cut -f1)

Explanation:
Removes conflicting Docker-related packages returned by dpkg. The nested command builds the package-name list dynamically.

Options:
- --get-selections = get selections: Shows the package selection states for the named packages.
- | = pipe: Sends dpkg output to cut.
- -f1 = --fields=1 (fields): Selects the first tab-delimited field, which contains the package name.
- $(...) = command substitution: Runs the nested pipeline and inserts its output as arguments to apt remove.

# sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc

Explanation:
Downloads Docker's Ubuntu repository signing key and saves it as /etc/apt/keyrings/docker.asc.

Options:

- -L = --location (location): Follows HTTP redirects.
- -o = --output (output): Writes the response to the specified file.

# sudo tee /etc/apt/sources.list.d/docker.sources <<EOF
Types: deb
URIs: https://download.docker.com/linux/ubuntu
Suites: $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}")
Components: stable
Architectures: $(dpkg --print-architecture)
Signed-By: /etc/apt/keyrings/docker.asc
EOF

Explanation:
Writes the Docker APT repository definition to /etc/apt/sources.list.d/docker.sources. The shell expands the Ubuntu codename and Debian architecture before tee writes the file.

Options:
- <<EOF = here-document operator: Sends all following lines up to the closing EOF marker to tee as standard input.
- $(...) = command substitution: Runs the enclosed command and inserts its output into the here-document.
- && = AND operator: Runs echo only if sourcing /etc/os-release succeeds.
- ${UBUNTU_CODENAME:-$VERSION_CODENAME} = parameter expansion: Uses UBUNTU_CODENAME when it is set and non-empty; otherwise uses VERSION_CODENAME.
- --print-architecture = print architecture: Makes dpkg print the package architecture, such as amd64.
