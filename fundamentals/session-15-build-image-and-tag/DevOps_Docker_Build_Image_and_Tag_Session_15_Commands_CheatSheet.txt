# FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

Explanation:
This Dockerfile uses the nginx:alpine base image, copies index.html into the Nginx web root, documents port 80, and starts Nginx in the foreground.

Options:
- -g = global configuration directives: Passes the global directive "daemon off;" to Nginx so it stays in the foreground.

# docker build \
  --build-arg HTTP_PROXY="$HTTP_PROXY" \
  --build-arg HTTPS_PROXY="$HTTPS_PROXY" \
  --build-arg NO_PROXY="$NO_PROXY" \
  -t myapp:1.0 \
  .

Explanation:
Builds myapp:1.0 and passes the current shell proxy environment values into the Docker build as build arguments.

Options:
- --build-arg = set build-time variable: Passes HTTP_PROXY="$HTTP_PROXY" to the build.
- --build-arg = set build-time variable: Passes HTTPS_PROXY="$HTTPS_PROXY" to the build.
- --build-arg = set build-time variable: Passes NO_PROXY="$NO_PROXY" to the build.
- -t = --tag (tag): Sets the image name and tag to myapp:1.0.
- $HTTP_PROXY = shell variable expansion: Uses the current value of the HTTP_PROXY environment variable.
- $HTTPS_PROXY = shell variable expansion: Uses the current value of the HTTPS_PROXY environment variable.
- $NO_PROXY = shell variable expansion: Uses the current value of the NO_PROXY environment variable.
- \ = shell line continuation: Continues the same command on the next physical line.
- . = current directory: Uses the current directory as the Docker build context.

# docker run -d --name session15-test -p 8085:80 session15-web:1.0

Explanation:
Starts a container from session15-web:1.0 in the background, names it session15-test, and publishes host port 8085 to container port 80.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = assign a name to the container: Sets the container name to session15-test.
- -p = --publish (publish): Publishes host port 8085 to container port 80 using 8085:80.
