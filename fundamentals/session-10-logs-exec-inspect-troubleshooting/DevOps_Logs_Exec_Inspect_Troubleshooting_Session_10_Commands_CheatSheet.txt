# docker run -d --name debug-web -p 8080:80 nginx:alpine

Explanation:
Creates and starts an Nginx container named debug-web in the background. It publishes host port 8080 to container port 80.

Options:
- -d = --detach (detach): Run the container in the background.
- --name debug-web = container name: Assign the name debug-web to the container.
- -p = --publish (publish): Publish a container port on the host.
- 8080:80 = port mapping value: Map host port 8080 to container port 80.

# docker run -d --name fail-demo alpine sh -c 'echo "Starting application"; sleep 2; echo "ERROR: config file not found" >&2; exit 2'

Explanation:
Creates a background Alpine container that prints messages, waits two seconds, writes an error to standard error, and exits with status 2.

Options:
- -d = --detach (detach): Run the container in the background.
- --name fail-demo = container name: Assign the name fail-demo to the container.
- -c = sh command string: Execute the following quoted string as shell commands.
- ; = shell command separator: Run the commands sequentially.
- >&2 = shell redirection: Redirect standard output of that echo command to file descriptor 2, standard error.
- 2 = exit status argument: Make the shell exit with status code 2.
