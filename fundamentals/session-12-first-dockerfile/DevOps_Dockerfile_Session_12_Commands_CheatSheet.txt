<html>
<head>
    <title>My First Docker Image</title>
</head>

    <h1>Hello from my first Dockerfile!</h1>
    <p>Docker is working.</p>
</body>
</html>

Creates or replaces index.html with the exact HTML content inside the here-document.

Options:
- > = output redirection: Sends the output of cat to index.html and truncates the file if it already exists.

# docker run -d --name my-web-container -p 8080:80 my-web:v1

Explanation:
Creates and starts a container named my-web-container from my-web:v1 in the background. It publishes host port 8080 to container port 80.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Assigns the container name my-web-container.
- -p = --publish (publish): Publishes a container port to the host.
- 8080:80 = publish value: Maps host port 8080 to container port 80.

# sed -i 's/Docker is working./Docker Image Version 2/' index.html

Explanation:
Edits index.html in place and replaces the first matching text on each line from Docker is working. to Docker Image Version 2.

Options:
- -i = --in-place (in-place): Edits index.html directly instead of writing the changed text only to standard output.
- 's/Docker is working./Docker Image Version 2/' = sed substitution expression: Replaces the matched text with the new text.

# ss -ltnp | grep 8080

Explanation:
Lists listening TCP sockets using numeric values and process information, then filters the output for 8080.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -t = --tcp (TCP): Shows TCP sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -p = --processes (processes): Shows the process using each socket when permitted.
- | = pipe operator: Sends the output of ss to grep as input.
