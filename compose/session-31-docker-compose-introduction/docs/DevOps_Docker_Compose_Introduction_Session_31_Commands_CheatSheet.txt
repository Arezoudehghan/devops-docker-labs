# docker run -d \
  --name postgres \
  -e POSTGRES_PASSWORD=123456 \
  -v postgres-data:/var/lib/postgresql/data \
  postgres

Explanation:
Runs a PostgreSQL container in the background with a fixed name, password environment variable, and persistent named volume.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name postgres = name: Assigns postgres as the container name.
- -e = --env (environment): Sets POSTGRES_PASSWORD=123456 inside the container.
- -v = --volume (volume): Mounts the named volume postgres-data at /var/lib/postgresql/data.
- \ = shell line continuation: Continues the same command on the next line.

# docker run -d \
  --name app \
  -p 8080:8080 \
  -e APP_ENV=production \
  -e DB_HOST=db \
  -v app-data:/data \
  --restart unless-stopped \
  myapp:1.0

Explanation:
Runs myapp:1.0 in the background with port mapping, environment variables, persistent storage, and a restart policy.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name app = name: Assigns app as the container name.
- -p = --publish (publish): Maps host port 8080 to container port 8080.
- -e = --env (environment): Sets APP_ENV=production and DB_HOST=db inside the container.
- -v = --volume (volume): Mounts the named volume app-data at /data.
- --restart unless-stopped = restart policy: Restarts the container automatically unless it was explicitly stopped.
- \ = shell line continuation: Continues the same command on the next line.

# sudo ss -lntp | grep ':18031' || true

Explanation:
Checks whether a TCP process is listening on port 18031. The final true prevents the overall shell command from failing when grep finds no match.

Options:
- sudo = superuser execution: Runs ss with elevated privileges.
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket when permissions allow.
- | = pipe operator: Sends the output of ss to grep.
- grep ':18031' = pattern filter: Keeps lines containing :18031.
- || = shell OR operator: Runs true only if the command on the left returns a non-zero status.
