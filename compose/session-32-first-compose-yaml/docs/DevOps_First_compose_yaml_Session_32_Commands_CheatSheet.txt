# ss -lntp | grep ':8080 ' || true

Explanation:
Lists listening TCP sockets numerically, shows the owning processes, and filters the result for port 8080. If grep finds no match, || true prevents the overall shell command from failing.

Options:
- -l = --listening (listening): Show only listening sockets.
- -n = --numeric (numeric): Do not resolve service names; show numeric addresses and ports.
- -t = --tcp (TCP): Show TCP sockets.
- -p = --processes (processes): Show the process using each socket.
- | = pipe operator: Send the output of ss to grep as input.
- ':8080 ' = grep search pattern: Match text containing port 8080 followed by a space.
- || = OR operator: Run the command on the right only if the command on the left fails.

# docker run -d \
  --name session32-nginx \
  -p 8080:80 \
  --restart unless-stopped \
  nginx:alpine

Explanation:
Creates and starts a detached Nginx container named session32-nginx, publishes host port 8080 to container port 80, and applies the unless-stopped restart policy.

Options:
- -d = --detach (detach): Run the container in the background.
- --name = container name: Set the container name to session32-nginx.
- -p = --publish (publish): Publish a container port to the host.
- 8080:80 = publish value: Map host port 8080 to container port 80.
- --restart = restart policy: Apply the restart policy supplied as its value.
- unless-stopped = restart policy value: Restart the container unless it was explicitly stopped.
- \ = shell line continuation: Continue the same command on the next line.

# cat > compose.yaml <<'EOF'

  web:
    image: nginx:alpine
    ports:
      - "8080:80"

Options:

- <<'EOF' = quoted here-document operator: Feed the following lines to cat until the ending EOF; quoting prevents shell expansion inside the here-document.
