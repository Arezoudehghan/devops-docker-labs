# sudo ss -lntp | grep -E ':(18033|18034)\b' || true

Explanation:
Checks whether TCP ports 18033 or 18034 are currently listening. If grep finds no match, true prevents the overall shell command from failing.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports without name resolution.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket.
- | = pipe operator: Sends the output of ss to grep.
- grep -E = --extended-regexp (extended regular expression): Interprets the search pattern as an extended regular expression.
- ':(18033|18034)\b' = grep pattern: Matches port 18033 or 18034 at a word boundary.
- || = OR operator: Runs the command on the right only if the command on the left fails.
