# docker compose ps -q app

Explanation:
Prints only the container ID for the `app` service.

Options:
- -q = --quiet (quiet): Displays only container IDs.
------------------------------------------------------------
# docker inspect "$(docker compose ps -q app)"

Explanation:
Gets the container ID of the `app` service and passes that ID to `docker inspect`.

Options:
- $() = command substitution: Runs `docker compose ps -q app` first and substitutes its output into the outer command.
- -q = --quiet (quiet): Makes the inner `docker compose ps` command return only the container ID.
