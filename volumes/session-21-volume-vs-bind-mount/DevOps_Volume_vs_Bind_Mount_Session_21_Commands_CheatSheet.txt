------------------------------------------------------------
# docker run -d \
  --name mysql \
  -e MYSQL_ROOT_PASSWORD=StrongPassword \
  -v mysql-data:/var/lib/mysql \
  mysql:8

Explanation:
Technical correction: the earlier MySQL example was incomplete because the official `mysql:8` image requires an initialization password or another supported initialization option. This corrected command starts MySQL in detached mode and stores its database files in the `mysql-data` volume.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Assigns the container name `mysql`.
- -e = --env (environment): Sets `MYSQL_ROOT_PASSWORD=StrongPassword` inside the container.
- -v = --volume (volume): Mounts the named volume `mysql-data` at `/var/lib/mysql`.
------------------------------------------------------------

------------------------------------------------------------
# docker run -d \
  --name nginx \
  -v /opt/website:/usr/share/nginx/html \
  nginx

Explanation:
Starts an Nginx container in the background and bind-mounts `/opt/website` from the host into the Nginx web root.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Assigns the container name `nginx`.
- -v = --volume (volume): Bind-mounts `/opt/website` to `/usr/share/nginx/html`.

  --name myapp \
  -v /srv/myapp/data:/app/data \
  myimage

Explanation:
Starts `myimage` in the background and bind-mounts the host directory `/srv/myapp/data` into `/app/data`.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Assigns the container name `myapp`.
- -v = --volume (volume): Bind-mounts `/srv/myapp/data` to `/app/data`.
------------------------------------------------------------

------------------------------------------------------------
# ls -lah /srv/myapp/data

Explanation:
Lists the contents of `/srv/myapp/data` in long format, including hidden files, with human-readable sizes.

Options:
- -l = --format=long (long format): Uses the long listing format.
- -a = --all (all): Includes hidden entries whose names start with a dot.
- -h = --human-readable (human-readable): Displays file sizes in readable units such as KB, MB, and GB.
------------------------------------------------------------

------------------------------------------------------------
# docker rm -f mysql

Explanation:
Removes the container named `mysql` even if it is currently running.

Options:
- -f = --force (force): Force-removes the running container.

# docker run --rm \
  -v /home/arezou/project:/app \
  myimage

Explanation:
Runs `myimage` with `/home/arezou/project` bind-mounted at `/app` and automatically removes the container when it exits.

Options:
- --rm = automatically remove the container: Removes the container automatically after it stops.
- -v = --volume (volume): Bind-mounts `/home/arezou/project` to `/app`.

# docker run -d \
  --name nginx \
  --mount type=volume,source=nginx-data,target=/usr/share/nginx/html \
  nginx

Explanation:
Starts Nginx in the background and mounts the named Docker volume `nginx-data` at `/usr/share/nginx/html`.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Assigns the container name `nginx`.
- --mount = mount specification: Creates a mount using `type=volume`, `source=nginx-data`, and `target=/usr/share/nginx/html`.
------------------------------------------------------------

Starts `myimage` in the background with `/opt/config` bind-mounted read-only at `/app/config`.

# docker run -d \
  --name nginx \
  -p 80:80 \
  -v /opt/nginx/nginx.conf:/etc/nginx/nginx.conf:ro \
  nginx

Explanation:
Starts Nginx in the background, publishes host port 80 to container port 80, and mounts a custom Nginx configuration file as read-only.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Assigns the container name `nginx`.
- -p = --publish (publish): Maps host port `80` to container port `80`.
- -v = --volume (volume): Bind-mounts `/opt/nginx/nginx.conf` to `/etc/nginx/nginx.conf`; the `:ro` suffix makes the mount read-only.
------------------------------------------------------------

# docker run --rm \
  -v lesson21-data:/data \
  alpine \
  sh -c 'echo "Created with Volume" > /data/test.txt'

Explanation:
Runs a temporary Alpine container that writes `Created with Volume` into `/data/test.txt` on the `lesson21-data` volume.

Options:
- --rm = automatically remove the container: Removes the container automatically after it stops.
- -v = --volume (volume): Mounts the named volume `lesson21-data` at `/data`.
- -c = command string: Tells `sh` to execute the following quoted command string.
- > = output redirection: Sends the output of `echo` to `/data/test.txt` and overwrites the file.
------------------------------------------------------------
