Explanation:
Runs ss with root privileges and shows listening TCP sockets, then filters the output for port 8085.

- -n = --numeric: Shows numeric addresses and port numbers instead of resolving names.
- -t = --tcp: Shows TCP sockets.
- -p = --processes: Shows the process using each socket when permissions allow it.
- | = pipe operator: Sends the output of ss to grep as input.

# sudo cp /etc/docker/daemon.json \
  /etc/docker/daemon.json.bak.$(date +%F-%H%M%S) \
  2>/dev/null || true

Explanation:
Copies daemon.json to a timestamped backup file. If the source file does not exist or the copy fails, the final true command keeps the compound command from returning a failure status.

Options:
- $(date +%F-%H%M%S) = command substitution: Runs date and inserts a timestamp such as YYYY-MM-DD-HHMMSS into the backup filename.
- +%F-%H%M%S = date format string: %F gives YYYY-MM-DD, %H gives hour, %M gives minute, and %S gives second.
- 2>/dev/null = stderr redirection: Sends file descriptor 2, standard error, to /dev/null.
- || = OR operator: Runs true only if the cp command fails.
- \ = line continuation: Continues the same shell command on the next line.
------------------------------------------------------------

# sudo python3 - <<'PY'
import json
from pathlib import Path

p = Path("/etc/docker/daemon.json")

data = {}

if p.exists() and p.stat().st_size:
    data = json.loads(p.read_text())

registries = set(data.get("insecure-registries", []))
registries.add("192.168.94.90:8085")

data["insecure-registries"] = sorted(registries)

p.write_text(json.dumps(data, indent=2) + "\n")
PY

Explanation:
Runs an inline Python script with root privileges. The script keeps existing daemon.json settings and adds 192.168.94.90:8085 to the insecure-registries list.

Options:
- - = standard input script source: Tells Python to read the program from standard input.
- <<'PY' = quoted here-document operator: Sends all lines up to PY to Python and prevents shell expansion inside the here-document.

# echo "$NEXUS_PASSWORD" \
  | docker login 192.168.94.90:8085 \
      -u "$NEXUS_USERNAME" \
      --password-stdin

Explanation:
Sends the value of NEXUS_PASSWORD to docker login through standard input and authenticates with the username stored in NEXUS_USERNAME.

Options:
- | = pipe operator: Sends echo output to docker login as standard input.
- -u = --username: Uses the value of NEXUS_USERNAME as the registry username.
- --password-stdin = password from standard input: Reads the registry password from standard input instead of a command-line value.
- "$NEXUS_PASSWORD" = quoted variable expansion: Expands NEXUS_PASSWORD while preserving its value as one shell argument.
- "$NEXUS_USERNAME" = quoted variable expansion: Expands NEXUS_USERNAME while preserving its value as one shell argument.
- \ = line continuation: Continues the same shell command on the next line.
