# docker login -u nexus-user -p MyPassword 192.168.94.90:8085

Explanation:
Authenticates to the Nexus Registry by supplying the username and password directly in the command.

Options:
- -u = --username (username): Uses nexus-user as the registry username.
- -p = --password (password): Uses MyPassword as the registry password.
------------------------------------------------------------
# printf '%s\n' "$NEXUS_PASSWORD" | docker login 192.168.94.90:8085 \
  --username "$NEXUS_USERNAME" \
  --password-stdin

Explanation:
Reads the Nexus password from the NEXUS_PASSWORD environment variable and sends it through standard input to docker login. The username is read from NEXUS_USERNAME.

Options:
- | = pipe operator: Sends the output of printf to the standard input of docker login.
- --username = username: Uses the value of NEXUS_USERNAME as the registry username.
- --password-stdin = password from standard input: Reads the registry password from standard input instead of the command line.
- \ = line continuation: Continues the same shell command on the next line.

# docker run -d \
  --name session42-nginx \
  -p 8042:80 \
  192.168.94.90:8085/labs/session42-nginx:1.0

Explanation:
Creates and starts a container named session42-nginx in the background from the Nexus image. It publishes container port 80 on host port 8042.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name = name: Sets the container name to session42-nginx.
- -p = --publish (publish): Maps host port 8042 to container port 80.
- \ = line continuation: Continues the same shell command on the next line.

# ss -lntp | grep 8085

Explanation:
Shows listening TCP sockets using numeric addresses and ports, including process information, then filters the output for port 8085.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and port numbers instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket when permissions allow it.
- | = pipe operator: Sends the output of ss to grep.
