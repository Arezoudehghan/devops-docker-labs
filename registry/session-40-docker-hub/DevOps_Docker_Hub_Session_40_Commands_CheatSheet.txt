# HEALTHCHECK --interval=30s --timeout=3s --start-period=5s --retries=3 \
  CMD wget -qO- http://127.0.0.1/ >/dev/null || exit 1

Explanation:
Defines a Docker image health check that requests the local web server and reports failure when the request fails.

Options:
- --interval=30s = health-check interval: Run the health check every 30 seconds.
- --timeout=3s = health-check timeout: Fail an individual check if it takes longer than 3 seconds.
- --start-period=5s = health-check start period: Give the container 5 seconds of startup time before normal failure counting.
- --retries=3 = health-check retries: Mark the container unhealthy after 3 consecutive failures.
- \ = shell line continuation: Continue the Dockerfile instruction on the next physical line.
- CMD = health-check command form: Run the following command as the container health test.
- -q = --quiet (quiet): Suppress normal wget output.
- -O = --output-document (output document): Write downloaded data to the specified destination; '-' means standard output.
- > = output redirection: Redirect wget standard output to /dev/null.
- || = logical OR: Run exit 1 only if wget fails.
- exit 1 = shell exit status: Return status code 1 to report a failed health check.

# ss -ltnp | grep ':18040' || true

Explanation:
Checks whether a TCP listener is using port 18040 and keeps the overall shell command successful when no match is found.

Options:
- -l = --listening (listening): Show only listening sockets.
- -t = --tcp (TCP): Show TCP sockets.
- -n = --numeric (numeric): Show numeric addresses and ports instead of resolving names.
- -p = --processes (processes): Show the process using each socket when permitted.
- | = pipe: Send ss output to grep.
- || = logical OR: Run true if grep returns a non-zero status.
- true = shell builtin: Return a successful exit status.
