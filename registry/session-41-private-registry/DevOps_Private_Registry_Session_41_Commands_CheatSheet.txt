# sudo ss -lntp | grep ':5005' || true

Explanation:
Shows listening TCP sockets and filters the result for port 5005. If grep finds no match, true prevents the command chain from ending with a failure status.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket.
- | = pipe operator: Sends the output of ss to grep.
- || = OR operator: Runs true only if the command on the left fails.

# sudo cp -a /etc/docker/daemon.json \
  /etc/docker/daemon.json.backup-session41 2>/dev/null || true

Explanation:
Copies daemon.json to a backup file while preserving its attributes. Errors are discarded, and true prevents a missing source file from causing the command chain to fail.

Options:
- -a = --archive (archive): Copies recursively when needed and preserves file attributes as much as possible.
- 2>/dev/null = stderr redirection: Sends standard error, file descriptor 2, to /dev/null.
- || = OR operator: Runs true only if the copy command fails.

# sudo python3 - <<'PY'
import json
from pathlib import Path

path = Path("/etc/docker/daemon.json")

if path.exists() and path.read_text().strip():
    data = json.loads(path.read_text())
else:
    data = {}

registry = "192.168.94.90:5005"

registries = data.get("insecure-registries", [])

if registry not in registries:
    registries.append(registry)

data["insecure-registries"] = registries

path.write_text(json.dumps(data, indent=2) + "\n")
PY

Explanation:
Runs an inline Python script that safely adds 192.168.94.90:5005 to the insecure-registries list in /etc/docker/daemon.json without overwriting unrelated settings.

Options:
- - = standard input script source: Tells python3 to read the program from standard input.
- <<'PY' = quoted here-document: Sends all lines up to PY to python3 and prevents shell expansion inside the here-document.
