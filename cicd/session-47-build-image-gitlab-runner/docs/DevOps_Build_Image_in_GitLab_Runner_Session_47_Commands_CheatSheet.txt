# sudo ss -ltnp | grep ':18047 ' || true

Explanation:
Lists listening TCP sockets with numeric addresses and process information, filters the output for port 18047, and prevents a no-match grep result from failing the whole shell command.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -t = --tcp (TCP): Shows TCP sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports without name resolution.
- -p = --processes (processes): Shows the process using each socket when permitted.
- | = pipeline operator: Sends the output of ss to grep.
- || = OR operator: Runs true only if the command on the left returns a non-zero status.
------------------------------------------------------------

# cat > .gitlab-ci.yml <<'EOF'
stages:
  - build

variables:
  IMAGE_NAME: "session47-app"
  IMAGE_TAG: "$CI_COMMIT_SHORT_SHA"
  BUILD_CONTEXT: "session47"

build_image:
  stage: build
  tags:
    - dev-shell

  before_script:
    - docker info

  script:
    - 'echo "Project dir: ${CI_PROJECT_DIR}"'
    - 'echo "Image: ${IMAGE_NAME}:${IMAGE_TAG}"'
    - docker build --tag "${IMAGE_NAME}:${IMAGE_TAG}" "${BUILD_CONTEXT}"
    - docker image inspect "${IMAGE_NAME}:${IMAGE_TAG}" --format 'ID={{.Id}}'
    - docker run --rm "${IMAGE_NAME}:${IMAGE_TAG}" nginx -t
    - docker image ls "${IMAGE_NAME}"
EOF

Explanation:
Creates or overwrites .gitlab-ci.yml with the GitLab CI pipeline used in this lesson. The here-document writes the YAML exactly as shown.

Options:
- > = output redirection: Sends cat output to .gitlab-ci.yml and overwrites the file.
- <<'EOF' = quoted here-document: Supplies the following YAML literally until EOF, without shell variable or command expansion.
