# HEALTHCHECK --interval=5s --timeout=2s --start-period=2s --retries=3 \
  CMD wget -qO- http://127.0.0.1/ >/dev/null || exit 1

Explanation:
Defines a Docker health check that requests the local Nginx page and marks the check as failed when the request fails.

Options:
- --interval=5s = health-check interval: Runs the health check every 5 seconds.
- --timeout=2s = health-check timeout: Allows each health check up to 2 seconds to finish.
- --start-period=2s = start period: Gives the container 2 seconds of startup time before health-check failures count normally.
- --retries=3 = retry count: Marks the container unhealthy after 3 consecutive failed checks.
- \ = Dockerfile line continuation: Continues the HEALTHCHECK instruction on the next line.
- -q = --quiet (quiet): Makes wget suppress normal output.
- -O- = --output-document=- (output document): Sends the downloaded content to standard output instead of a file.
- > = shell output redirection: Sends standard output to /dev/null.
- || = shell OR operator: Runs exit 1 only if wget fails.
