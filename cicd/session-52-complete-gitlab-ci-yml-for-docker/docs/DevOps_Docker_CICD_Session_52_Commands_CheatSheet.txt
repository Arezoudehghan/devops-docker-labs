  --pull \
  --build-arg HTTP_PROXY="${HTTP_PROXY}" \

  --build-arg NO_PROXY="${NO_PROXY}" \

  .

- --build-arg NO_PROXY="${NO_PROXY}" = build argument: Passes the current NO_PROXY value into the build.
- --tag "${IMAGE_REF}" = image name and tag: Names and tags the built image with the value of IMAGE_REF.

# ssh -i ~/.ssh/id_ed25519 \
  "${DEPLOY_USER}@${DEPLOY_HOST}" \
  "
    set -eu

    docker pull '${IMAGE_REF}'

    docker rm -f '${CONTAINER_NAME}' \
      >/dev/null 2>&1 || true

    docker run -d \
      --name '${CONTAINER_NAME}' \
      --restart unless-stopped \
      -p '${DEPLOY_PORT}:${APP_PORT}' \
      '${IMAGE_REF}'
  "

Explanation:
Connects to the deployment server and runs the complete remote deployment sequence: strict shell mode, image pull, old-container replacement, and startup of the new container.

Options:
- -i = identity file: Uses ~/.ssh/id_ed25519 as the SSH private key.
- -e = errexit: Stops the remote shell on an unhandled command failure.
- -u = nounset: Fails when the remote shell references an unset variable.
- -f = --force (force): Force-removes the old container if it exists.
- > = output redirection: Redirects standard output from the removal command to /dev/null.
- 2>&1 = file-descriptor redirection: Sends standard error to the same destination as standard output.
- || = OR operator: Runs true if old-container removal fails, such as on the first deployment.
- -d = --detach (detach): Runs the new container in the background.
- --name '${CONTAINER_NAME}' = container name: Assigns the configured production container name.
- --restart unless-stopped = restart policy: Restarts the container automatically unless it was explicitly stopped.
- -p = --publish (publish): Maps ${DEPLOY_PORT} on the host to ${APP_PORT} in the container.
