# docker build -t my-app:abc12345 .

Explanation:
Builds a Docker image from the Dockerfile in the current directory and names it my-app with the tag abc12345.

Options:
- -t = --tag (tag): Sets the image name and optional tag.
- . = build context: Uses the current directory as the Docker build context.

# docker info | sed -n '/Insecure Registries/,+10p'

Explanation:
Displays Docker information and prints the Insecure Registries section plus the next ten lines.

Options:
- | = pipe operator: Sends the output of docker info to sed as input.
- -n = --quiet / --silent: Suppresses sed's automatic printing.
- '/Insecure Registries/,+10p' = sed address and print command: Starts at the matching line, includes the next ten lines, and prints that range.

# docker build --pull -t "${IMAGE_NAME}:${IMAGE_TAG}" .

Explanation:
Builds the Docker image, attempts to refresh referenced base images, and tags the result with the Nexus image name and commit-based tag.

Options:
- --pull = always attempt to pull newer referenced images: Checks for a newer version of referenced base images before building.
- -t = --tag (tag): Sets the image name and tag.
- . = build context: Uses the current directory as the Docker build context.
------------------------------------------------------------

------------------------------------------------------------
# printf '%s' "${NEXUS_PASSWORD}" | docker --config "${CI_PROJECT_DIR}/.docker" login "${NEXUS_REGISTRY}" --username "${NEXUS_USERNAME}" --password-stdin

Explanation:
Sends the Nexus password through standard input and logs Docker in to the Nexus registry using a temporary Docker configuration directory.

Options:
- '%s' = printf string format: Prints the password value as a string without adding extra text.
- | = pipe operator: Sends printf output to docker login as standard input.
- --config "${CI_PROJECT_DIR}/.docker" = Docker configuration directory: Uses this directory instead of the default Docker CLI configuration directory.
- --username "${NEXUS_USERNAME}" = username: Supplies the Nexus username.
- --password-stdin = password from standard input: Reads the password from standard input instead of a command-line argument.
------------------------------------------------------------
