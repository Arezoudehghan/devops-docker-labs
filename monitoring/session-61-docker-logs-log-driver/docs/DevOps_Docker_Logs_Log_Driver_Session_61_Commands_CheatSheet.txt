  sh -c 'i=1; while true; do echo "request=$i"; i=$((i+1)); sleep 2; done'

Explanation:
Starts a detached lab container using json-file logging with 10 MB rotation size and three retained log files.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name log-test = name: Assigns the container name.
- --log-driver json-file = log driver: Selects json-file logging.
- --log-opt max-size=10m = log option: Rotates the current log file at about 10 MB.
- --log-opt max-file=3 = log option: Keeps up to three rotated log files.
- sh -c = command string: Executes the quoted shell loop; -c tells sh to run the supplied string.
- $((i+1)) = arithmetic expansion: Increments i.
- ; = command separator: Runs the shell statements in sequence.
