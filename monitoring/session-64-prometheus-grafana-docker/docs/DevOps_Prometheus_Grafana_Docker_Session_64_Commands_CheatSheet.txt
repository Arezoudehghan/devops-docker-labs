# sudo ss -lntp | grep -E ':(9094|3004)\b' || true

Explanation:
Checks whether TCP ports 9094 or 3004 are already listening and suppresses a non-match failure.

Options:
- -l = --listening (listening): Show only listening sockets.
- -n = --numeric (numeric): Show numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Show TCP sockets.
- -p = --processes (processes): Show the process using each socket.
- | = pipe operator: Send ss output to grep.
- -E = --extended-regexp (extended regular expression): Use extended regular expression syntax in grep.
- || = OR operator: Run true only if grep returns a non-zero status.
- true = shell command that always succeeds: Prevents the whole command from failing when no matching port is found.

# printf 'GRAFANA_ADMIN_PASSWORD=%s\n' "$(openssl rand -hex 12)" > .env

Explanation:
Creates the .env file with a randomly generated Grafana administrator password.

Options:
- %s = printf string placeholder: Inserts the generated password into the output line.
- \n = newline escape: Ends the generated line with a newline.
- $(...) = command substitution: Runs openssl rand -hex 12 and inserts its output into printf.
- -hex = hexadecimal output: Makes openssl rand print the random bytes as hexadecimal text.
- 12 = rand byte count: Generates 12 random bytes before hexadecimal encoding.
- > = output redirection: Replaces .env with the generated output.

# cat > /opt/docker-labs/session64/compose.yaml <<'EOF'
services:

  prometheus:
    image: prom/prometheus:v3.14.0
    container_name: session64-prometheus
    restart: unless-stopped

    ports:
      - "9094:9090"

    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml:ro
      - prometheus_data:/prometheus

    command:
      - --config.file=/etc/prometheus/prometheus.yml
      - --storage.tsdb.path=/prometheus
      - --storage.tsdb.retention.time=7d

    extra_hosts:
      - "host.docker.internal:host-gateway"

    networks:
      - monitoring


  grafana:
    image: grafana/grafana:13.2.0
    container_name: session64-grafana
    restart: unless-stopped

    ports:
      - "3004:3000"

    environment:
      GF_SECURITY_ADMIN_USER: admin
      GF_SECURITY_ADMIN_PASSWORD: ${GRAFANA_ADMIN_PASSWORD}
      GF_USERS_ALLOW_SIGN_UP: "false"

    volumes:
      - grafana_data:/var/lib/grafana
      - ./grafana/provisioning/datasources:/etc/grafana/provisioning/datasources:ro

    depends_on:
      - prometheus

    networks:
      - monitoring


networks:
  monitoring:
    name: session64-monitoring
    driver: bridge


volumes:
  prometheus_data:
    name: session64-prometheus-data

  grafana_data:
    name: session64-grafana-data
EOF

Explanation:
Creates the Docker Compose file for the Prometheus and Grafana monitoring stack.

Options:
- > = output redirection: Replaces the target file with the here-document content.
- <<'EOF' = quoted here-document operator: Reads the following lines until EOF without shell variable or command expansion.
- --config.file=/etc/prometheus/prometheus.yml = Prometheus option: Sets the Prometheus configuration file path.
- --storage.tsdb.path=/prometheus = Prometheus option: Sets the time-series database storage path.
- --storage.tsdb.retention.time=7d = Prometheus option: Keeps time-series data for 7 days.

- \ = shell line continuation: Continue the same command on the next line.
- | = pipe operator: Send the JSON response from curl to Python.
