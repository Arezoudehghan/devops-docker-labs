# docker logs cadvisor 2>&1 | tail -50

Explanation:
Reads the cAdvisor container logs, combines standard error with standard output, and shows the last 50 lines.

Options:
- 2>&1 = shell redirection: Redirects file descriptor 2, standard error, to file descriptor 1, standard output.
- | = pipe operator: Sends the combined log output to tail.
- -50 = last 50 lines: GNU tail shorthand for showing the last 50 lines, equivalent to -n 50.

# docker rm -f alert-demo 2>/dev/null || true

Explanation:
Removes the alert-demo container if it exists and prevents the shell command from failing when the container is missing.

Options:
- -f = --force (force): Forces removal of the container, including stopping it first if necessary.
- 2>/dev/null = shell redirection: Sends standard error to /dev/null so error messages are hidden.
- || = OR operator: Runs the command on the right only if the command on the left fails.
------------------------------------------------------------
# docker run -d \
  --name alert-demo \
  --memory=128m \
  --cpus=1 \
  python:3.12-slim \
  sleep infinity

Explanation:
Creates a detached container named alert-demo with a 128 MiB memory limit and a one-CPU limit, then keeps it running with sleep infinity.

Options:
- -d = --detach (detach): Runs the container in the background.
- --name alert-demo = container name: Assigns the name alert-demo.
- --memory=128m = memory limit: Limits container memory to 128 MiB.
- --cpus=1 = CPU limit: Limits the container to one CPU.
- python:3.12-slim = image argument: Uses the Python 3.12 slim image.
- sleep infinity = container command: Keeps the container alive indefinitely.
- \ = shell line continuation: Continues the same command on the next line.
