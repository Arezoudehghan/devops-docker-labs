# sudo ss -lntp | grep ':8080' || true

Explanation:
Shows listening TCP sockets and searches the result for port 8080. If no match is found, the final true command prevents the shell command from being treated as failed.

Options:
- -l = --listening (listening): Show only listening sockets.
- -n = --numeric (numeric): Show numeric addresses and port numbers instead of resolving names.
- -t = --tcp (TCP): Show TCP sockets.
- -p = --processes (processes): Show the process using each socket when permitted.
- | = pipe operator: Send the output of ss to grep.
- || = OR operator: Run true only if the command on the left returns a non-zero status.

# docker rm -f cadvisor 2>/dev/null || true

Explanation:
Force-removes the cadvisor container if it exists. Error output is discarded, and the command is treated as successful even when the container does not exist.

Options:
- -f = --force (force): Force removal of the running container by sending SIGKILL.
- 2> = standard-error redirection: Redirect file descriptor 2, which is stderr.
- /dev/null = redirection target: Discard the redirected error output.
- || = OR operator: Run true if docker rm returns a non-zero status.

# docker run -d \
  --name cadvisor \
  --restart unless-stopped \
  --volume=/:/rootfs:ro \
  --volume=/var/run:/var/run:ro \
  --volume=/sys:/sys:ro \
  --volume=/var/lib/docker/:/var/lib/docker:ro \
  --volume=/dev/disk/:/dev/disk:ro \
  --publish=192.168.94.91:8080:8080 \
  --privileged \
  --device=/dev/kmsg \
  ghcr.io/google/cadvisor:v0.60.5

Explanation:
Runs cAdvisor in the background with access to the host paths and devices needed for container monitoring. It publishes the cAdvisor service on 192.168.94.91 port 8080.

Options:
- -d = --detach (detach): Run the container in the background and print its container ID.
- --name cadvisor = container name: Assign the name cadvisor to the container.
- --restart unless-stopped = restart policy: Restart the container automatically unless it was explicitly stopped.
- --volume=/:/rootfs:ro = volume mount: Mount the host root filesystem at /rootfs inside the container as read-only.
- --volume=/var/run:/var/run:ro = volume mount: Mount /var/run from the host at the same path inside the container as read-only.
- --volume=/sys:/sys:ro = volume mount: Mount /sys from the host at the same path inside the container as read-only.
- --volume=/var/lib/docker/:/var/lib/docker:ro = volume mount: Mount Docker's data directory inside the container as read-only.
- --volume=/dev/disk/:/dev/disk:ro = volume mount: Mount host disk device information inside the container as read-only.
- --publish=192.168.94.91:8080:8080 = published port mapping: Bind host IP 192.168.94.91 and host port 8080 to container port 8080.
- --privileged = privileged mode: Give the container extended privileges and broad access to host devices.
- --device=/dev/kmsg = device mapping: Make the host /dev/kmsg device available inside the container.
