# docker ps

Explanation:
Lists the currently running Docker containers.

# docker ps --format 'table {{.Names}}\t{{.Image}}\t{{.Ports}}' | grep -i node

Explanation:
Lists running containers in a custom table and filters the result for lines containing "node" regardless of letter case.

Options:
- --format = format: Formats the `docker ps` output using the supplied Go template.
- | = pipe operator: Sends the output of `docker ps` to `grep`.
- -i = --ignore-case (ignore case): Makes `grep` match "node" without case sensitivity.

------------------------------------------------------------
# sudo ss -lntp | grep ':9100' || true

Explanation:
Shows listening TCP sockets in numeric form with process information, filters for port 9100, and prevents the shell command from failing if no match is found.

Options:
- -l = --listening (listening): Shows only listening sockets.
- -n = --numeric (numeric): Shows numeric addresses and ports instead of resolving names.
- -t = --tcp (TCP): Shows TCP sockets.
- -p = --processes (processes): Shows the process using each socket.
- | = pipe operator: Sends the output of `ss` to `grep`.
- || = OR operator: Runs `true` only if the previous pipeline returns a non-zero status.

# services:

  node-exporter:
    image: quay.io/prometheus/node-exporter:v1.12.1
    container_name: node-exporter

    command:
      - '--path.rootfs=/host'

    network_mode: host

    pid: host

    restart: unless-stopped

    volumes:
      - '/:/host:ro,rslave'

Explanation:
Defines a Docker Compose service for Node Exporter so it can monitor the Linux host instead of only its own container environment.

Options:
- image = `quay.io/prometheus/node-exporter:v1.12.1`: Pins the Node Exporter container image to version `v1.12.1`.
- container_name = `node-exporter`: Sets the container name explicitly.
- command = `--path.rootfs=/host`: Tells Node Exporter to treat `/host` as the host root filesystem.
- network_mode = `host`: Uses the host network namespace.
- pid = `host`: Uses the host PID namespace.
- restart = `unless-stopped`: Restarts the container automatically unless it was intentionally stopped.
- volumes = `/:/host:ro,rslave`: Mounts the host root filesystem at `/host` as read-only with recursive slave mount propagation.

# 100 - (
  avg by(instance) (
    rate(node_cpu_seconds_total{mode="idle"}[5m])
  ) * 100
)

Explanation:
PromQL query that estimates host CPU usage percentage by subtracting the five-minute average idle CPU rate from 100 percent.

Options:
- [5m] = range selector: Uses samples from the previous five minutes.
- mode="idle" = label matcher: Selects only CPU time spent in idle mode.
