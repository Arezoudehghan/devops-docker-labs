# docker rm -f session60-logger 2>/dev/null || true

Explanation:
Removes the session60-logger container if it already exists. Errors are hidden so the cleanup does not stop the shell workflow when the container is absent.

Options:
- -f = --force (force): Forces removal of the running container.
- 2>/dev/null = stderr redirection: Sends file descriptor 2 (standard error) to /dev/null.
- || = OR operator: Runs true only if the docker rm command fails.

# docker run -d \
  --name session60-logger \
  --log-driver json-file \
  --log-opt max-size=1m \
  --log-opt max-file=3 \
  alpine:3.20 \
  sh -c 'i=1; while true; do echo "INFO request=$i status=200"; echo "ERROR request=$i demo-error" >&2; i=$((i+1)); sleep 2; done'

Explanation:
Starts a detached Alpine container that continuously writes INFO messages to stdout and ERROR messages to stderr every two seconds. The container uses the json-file logging driver with per-container log rotation limits.

Options:
- -d = --detach (detach): Runs the container in the background and prints its container ID.
- --name = assign a name: Names the container session60-logger.
- --log-driver = logging driver: Uses json-file for this container.
- --log-opt max-size=1m = logging option value: Limits each log file to 1 MB before rotation.
- --log-opt max-file=3 = logging option value: Keeps at most 3 rotated log files.
- sh -c = execute command string: -c tells the shell to execute the following quoted script.
- >&2 = stderr redirection: Sends the ERROR echo output to file descriptor 2 (standard error).
- $((i+1)) = arithmetic expansion: Calculates the next integer value for i.

# sudo test -f /etc/docker/daemon.json \
  && sudo cat /etc/docker/daemon.json \
  || echo "daemon.json does not exist"

Explanation:
Checks whether /etc/docker/daemon.json is a regular file and prints it when the test succeeds. If the preceding command chain fails, it prints daemon.json does not exist.

Options:
- -f = regular-file test: Returns success when /etc/docker/daemon.json exists and is a regular file.
- && = AND operator: Runs sudo cat /etc/docker/daemon.json only when the test command succeeds.
- || = OR operator: Runs the final echo command if the command chain before it fails.
------------------------------------------------------------
